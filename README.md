# Electiva2_SubastasEnLinea_EleanisAreiza
Proyecto del programa ingeniería en software de la materia Electiva2 Desarrollo de Software

**Nombre de la Materia:** Electiva2 Desarrollo de Software

**Nombre del Proyecto:** Subasta En Línea

**Equipo:** Equipo Ele

**Integrantes:**
* Eleanis Areiza Lopez
  
**Descripción:**
Este proyecto implementa una plataforma de subastas en línea, donde los vendedores publican artículos con precio base y fecha de cierre, 
los compradores realizan ofertas en tiempo real, y al finalizar la subasta la oferta más alta genera una orden de pago procesada por una pasarela.
